Points d'Attention & Vulnérabilités Détectées :
⚠️ Risque d'Usurpation de Rôle (audit.controller.ts) MAJEUR

L'authentification Admin vérifie directement req.headers['x-user-role'] === 'admin'. Si l'appel contourne l'API Gateway ou si Nginx ne purge pas les en-têtes entrants, un client externe peut forger ce rôle.

// Code actuel :
const userRole = req.headers['x-user-role'] as string;
if (userRole !== UserRole.ADMIN) { return res.status(403)... }
// Remédiation recommandée :
Vérifier cryptographiquement le JWT ou valider la clé secrète inter-services (X-Internal-Token).
ℹ️ Cohérence Route OpenAPI

Route déclarée /api/v1/auth/register-dev dans identity-api au lieu de /api/v1/auth/register tel que documenté dans openapi.yaml.
